# Workspace-specific access preferences

- For explicitly requested GitHub and SonarQube tasks in this workspace, try the available integration or authenticated CLI outside the sandbox when sandbox restrictions block access. Do not ask the user whether outside-sandbox access is available; they have confirmed it is.
- This preference does not bypass platform approval prompts, authentication requirements, or the need for explicit user authorization for external changes. If access still fails, report the exact blocker instead of asking whether outside-sandbox access exists.
